One line, 1–240 characters, that gives the judge a quiet, earned moment of pride for someone in a scene — a small person doing something hard, a long effort finally landing. Built for the [make.fun](https://make.fun/c/u-mang-one-line-of-earned-pride-a0138557) bounty "One Line of Earned Pride".

The program writes the line to `/output/entry.txt`:

> Three nights of cold joints and burnt fingertips, and then at 2 a.m. she held the board to the light — the little green LED stayed on.

Run it with Node 22+:

```sh
node main.ts
```
